# Registro — 21 de outubro de 2026

Três melhorias de layout e UI completadas:

1. **Full-width em desktop** — Permitir que todas as páginas ocupem 100% da largura em telas >900px (anteriormente limitadas a 480px até em Mac). Remover padding horizontal das abas para os campos de dados encostarem nas laterais.

2. **Padronizar Notebook** — Converter de modal overlay para página padrão com cabeçalho azul, seta para voltar e estrutura como Pauta/Check-in/RDO.

3. **Eliminar tarja de módulo** — Remover o badge visual (PAUTA, PLANEJAMENTO, NOTEBOOK, CUSTOS, etc.) que aparecia no topo esquerdo de cada página. Com o novo layout full-width e header azul padrão, a identidade do módulo está clara na barra de título.

- Remover botão X e ajustar estrutura para seguir padrão de outras páginas (Pauta, Check-in, RDO)
- Remover elemento HTML `<div class="mod-card">` e função `atualizarHeroModulo()` — tarja não mais necessária
- Atualizar suite de testes para refletir remoção da tarja
